# MVP 验收清单

企业能够：

1. 创建账号（注册）  
2. 创建组织 / 工作区（已认证）  
3. 添加授权的财务用户（成员邀请）  
4. 登记供应商  
5. 添加已批准的供应商付款目的地  
6. 上传发票  
7. 抽取发票信息  
8. 审核并核验发票  
9. 配置审批策略  
10. 提交付款以待审批  
11. 取得所需审批  
12. 配置绑定 TapeOut 处理器 + 电路的付款策略  
13. 评估付款策略（RPC 可用时实时 TapeOut `eval`；仅启用时本地回退）  
14. 收到授权决策  
15. 执行 USDC 付款（测试网 / 主网合约 **或** 受控模拟）  
16. 确认交易（确认数）  
17. 将交易与发票关联  
18. 对账付款  
19. 查看完整审计历史  

## 负向用例

Foundry 测试与 API 守卫覆盖：

- 未授权角色被 RBAC 拒绝  
- 未批准供应商目的地无法验证 / 供应商门禁失败  
- 目的地变更使审批失效（承诺不匹配）  
- 发票不能付两次（幂等 / 重放）  
- 策略拒绝阻塞结算  
- TapeOut 失败阻塞链上 authorize  
- 过期授权不能复用（合约）  
- 金库余额不足阻止付款（合约）  
- 无确认数不把失败交易报为完成  
- 模拟结算需明示环境标志
